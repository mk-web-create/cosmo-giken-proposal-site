# コスモ技建株式会社 営業提案用サンプル（通常のHTML版）

React版を残したまま、Node.jsや開発サーバーを使わずに閲覧・編集できる形式へ変換したものです。公開、デプロイ、GitHubへのpushは行っていません。

## 開き方

`index.html` をダブルクリックしてください。通常のWebブラウザでそのまま開きます。

インターネット接続、Node.js、npm、ビルド作業、ローカルサーバーは必要ありません。

## ファイル構成

- `index.html`：文章、会社情報、ページの構造
- `style.css`：色、文字サイズ、余白、PC・スマートフォンのレイアウト
- `script.js`：スマートフォンメニューとデモフォームの表示
- `assets/images/`：ページ内で使う画像4点
- `screenshots/`：変換後のPC・スマートフォン表示

## 編集する場所

### 文章や会社情報

`index.html`をメモ帳やコードエディターで開き、表示されている日本語を変更します。HTMLタグの `<` と `>` は消さず、タグの間にある文章だけを変更してください。

### 画像

`assets/images`内の画像を差し替えます。同じファイル名で上書きすれば、HTMLを変更せずに差し替えられます。

- `hero-living.png`：メイン写真
- `new-construction.png`：新築・住宅外観
- `renovation.png`：リフォーム・室内
- `shop.png`：店舗の設計・施工

別のファイル名を使う場合は、`index.html`内の `src="assets/images/画像名"` を変更してください。

### 色

`style.css`の先頭にある `:root` 内を変更します。

- `--paper`：クリーム色の背景
- `--ink`：本文の文字色
- `--green`：ボタンなどの緑
- `--green-deep`：濃い緑の背景
- `--wood`：木をイメージした茶色

## フォント

外部フォントや有料フォントは同梱していません。Windowsに標準搭載されている日本語フォントを優先し、利用できない環境ではブラウザの明朝体・ゴシック体へ自動的に切り替わります。

## フォームについて

相談フォームは入力デモです。送信先、外部通信、ブラウザ保存処理はありません。ボタンを押すと「内容は送信されません」と表示するだけです。
