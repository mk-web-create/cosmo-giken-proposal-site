# コスモ技建株式会社 営業提案用サンプル（4ページ通常HTML版）

コスモ技建株式会社向けに制作した、営業提案用の非公式・ローカル参考サイトです。公開、デプロイ、GitHubへのpushは行っていません。

## 開き方

`index.html` をダブルクリックしてください。Node.js、npm、ビルド、ローカルサーバーは必要ありません。4ページは相対パスでつながっているため、そのまま移動できます。

## ファイル構成

- `index.html`：トップページ
- `company.html`：会社概要
- `contact.html`：お問い合わせ・非送信デモフォーム
- `recruit.html`：採用ページの構成サンプル
- `style.css`：全ページ共通のデザインとレスポンシブ表示
- `script.js`：スマートフォンメニューとデモフォームの表示
- `assets/images/`：参考イメージ4点
- `screenshots/`：PC・スマートフォンの確認画像

## 編集する場所

- 文章・会社情報・メニュー：各HTMLファイル
- 色：`style.css` 冒頭の `:root`
- 写真：`assets/images/` の画像。別名にする場合はHTMLの `src` も変更
- フォームの説明表示：`script.js` の `formResult.textContent`

HTMLタグの `<` と `>` は消さず、タグの間の文章を変更してください。

## フォームと採用情報

お問い合わせフォームは入力デモです。`form` に送信先はなく、操作ボタンは `type="button"` です。入力値を読み取る処理、外部通信、URL出力、ログ出力、ブラウザ保存処理はありません。

採用ページは構成サンプルです。募集職種、雇用形態、給与、勤務時間、休日、勤務地、福利厚生、応募資格は未確認のため、すべて「正式制作時に掲載」としています。応募ボタンは無効で、実際の応募は受け付けません。
